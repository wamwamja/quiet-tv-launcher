# Quiet TV Launcher

一个关于智能电视「老年模式」的小探索，分享给有同样需要的人。

## 为什么做这个桌面

现在的智能电视功能越来越多，首页也越来越热闹：推荐内容、广告、会员入口和各种应用挤在一起，菜单层级复杂，找一个熟悉的节目或切回机顶盒，往往要按好几次遥控器。对一些老年人来说，这些花里胡哨的界面增加了使用负担，原本简单的“打开电视看节目”反而变得不容易。

这个项目从一个朴素的需求出发：让家里的长辈打开电视后，能看懂眼前的界面，找到常看的内容，用熟悉的遥控器完成操作。

因此，首页把“看电视”放在主要位置，直接显示机顶盒的实时预览，按确定就进入播放；旁边只留四个常用应用入口。整体采用简洁的布局和清晰的焦点反馈，把切换信号源、应用排序等低频操作收进长按菜单，减少日常选择和误操作。

这还只是一次「老年模式」的探索。不同长辈的习惯、视力和操作能力不同，目前也只在一款电视上完成实机验证，还需要更多实际使用反馈。把它开源，是希望给有类似需求的人一个可以使用、修改和继续完善的起点，也欢迎分享长辈使用时遇到的问题。

## 功能

- 首页静音电视小窗，短按确定进入系统信号源播放器；Home 返回预览。
- 长按电视卡片的确定键选择信号源；标记已连接接口，断开时显示无信号。
- 首页四个应用入口；应用库连续滚动，支持长按管理与排序；上下入口采用可聚焦的两步过渡提示。
- 首页和应用库统一图标底座、清水材质聚焦；网络和设置采用紧凑胶囊。
- 导航到边界时出现轻微回弹和方向水光；电视预览只显示水光，画面位置不动。
- 小米菜单键打开原生侧边面板，兼容固件注入的特殊菜单事件。
- 返回已有首页时复用布局，重连时保持视频区域尺寸固定。

## 已验证设备

| 项目 | 已验证环境 |
| --- | --- |
| 电视 | 小米 S55 Mini LED 国行，MiTV-MFTR0 / freeguy |
| 固件 | HyperOS 3.0.106.0，Android 14 |
| 信号 | HDMI 3 机顶盒；其他 HDMI 空闲口无信号状态 |

最低构建支持 Android 8（API 26），不代表所有设备都能使用实时预览。预览依赖厂商 TvInput 服务；全屏播放优先交给系统处理。当前仅上述小米设备验证过原生路由，其他设备采用标准输入 URI，仍需实机适配。
