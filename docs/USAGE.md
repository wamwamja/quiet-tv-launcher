# 使用教程

这个桌面是面向老年人日常看电视场景的一次探索。安装与配置涉及 ADB，建议由熟悉电脑操作的家人先完成，再陪长辈试用“看电视”、打开常用应用和 Home 返回等操作，按实际习惯调整首页入口。

## 1. 先按 CleanYourTV 准备电视

直接参考 **[CleanYourTV 官方仓库及使用说明](https://github.com/Gathin23/cleanyourtv)**，包括 ADB 连接、设备适配、系统桌面替换及恢复操作。设备差异以该项目对应文档和你电视的实际情况为准，不把其他型号的禁用清单套用到自己的电视。

本项目只提供独立启动器。无需为了使用它而运行整套去广告操作。CleanYourTV 自带 launcher 与本项目是不同构建，后续运行上游安装流程时注意不要覆盖当前选择的版本。

## 2. 构建并安装

先阅读 [BUILD.md](BUILD.md)。下例是已验证小米设备使用的包名，其他电视按适配需求选择。`TV_IP` 换成自己的电视地址；在电视端允许 ADB 授权。

```sh
adb connect TV_IP:5555
adb -s TV_IP:5555 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s TV_IP:5555 shell am start -n com.ts.launcher/com.gathin.tvhome.MainActivity
```

如果设备不支持流式安装，可以先 `adb push` 到 `/data/local/tmp/`，再通过 `adb shell pm install -r` 安装。

首次先直接打开应用确认画面和遥控器可用，再按 CleanYourTV 的对应设备说明设置 Home。仓库不替你禁用原生桌面。升级已有同包名应用需要相同签名；请勿为了绕过签名错误而直接卸载正在使用的唯一桌面。

## 3. 遥控器操作

| 操作 | 结果 |
| --- | --- |
| 电视卡片短按确定 | 进入系统信号源播放器，由系统处理声音 |
| 电视卡片长按确定 | 选择 HDMI / AV 等可用信号源 |
| Home | 返回首页静音预览；已在首页时复用现有视图 |
| 菜单键 | 已验证小米设备打开原生侧边面板；不支持时回退桌面设置 |
| 应用短按确定 | 打开应用 |
| 应用长按确定 | 添加/移除首页入口、调整排序 |
| 应用库第二行向下 | 有下一页时翻页；下一页第一行向上返回上一页 |
| 设置长按确定 | 打开原生设置 |

绿色连接标记来自系统报告的接口状态，不保证连接设备正在输出有效节目。无信号时检查设备电源和连线。切换信号源会记住当前选择；首次在已验证小米型号上沿用 HDMI 3 默认值，其他型号需自行选择。

## 4. 恢复

直接参考 [CleanYourTV 的恢复说明](https://github.com/Gathin23/cleanyourtv)及对应型号记录。先恢复并验证原生 Home，再停用替代桌面。

维护期间自行决定何时关闭 ADB，本应用不会自动关闭 ADB。

## 已知边界

- 截图通常不包含 HDMI 硬件视频层，截图黑色不等于实机无画面。
- 从系统播放器返回需要重新建立预览会话；连接期间是固定底色区域，准备好后显示视频。
- 字体使用电视系统字体，与 macOS/浏览器字形可能略有差异。
- 非设计预置的第三方应用使用原始应用图标并套用统一容器。
